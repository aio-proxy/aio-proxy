Track shared proxy usage by named API key with an independent user ranking, whole-dashboard user filtering and caller attribution in traces. The ranking is shown when API key access is enabled, including for a single user. Saving keys requires unique labels; caller identity survives key rotation and usage history remains available after traces expire.
