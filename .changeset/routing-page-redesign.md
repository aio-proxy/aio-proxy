The routing page groups models by vendor using models.dev's display naming rules, shows four health metrics as dashboard cards, and filters model IDs and vendors in one row. Each model shows named Providers with OAuth service and account labels, traffic share, and success rate beside its configured Provider weights. Routing tiers use one shared label and reveal their numeric priority on hover. Editing a route is a full page instead of a drawer.
