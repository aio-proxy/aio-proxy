Let a mouse open a combobox that has a clear button. Every combobox built from the shared input
primitive hid its chevron as soon as a value was set, and the input itself only opens on typing or
ArrowDown — so the AI SDK package field, which is never empty because it defaults to a package,
offered a pointer user no way to see or reach its curated package list, and the models.dev extend
field lost the same affordance once a slug was picked. The chevron now stays beside the clear button
instead of being replaced by it. The clear button is also no longer an anonymous icon: it takes a
translated accessible name, and the package field's visible "Package Name" label is once again the
input's accessible name rather than being shadowed by a duplicate `aria-label`.
