# Dashboard Overview

AIO Proxy ships with a built-in, lightweight web dashboard for managing providers, inspecting live requests, and monitoring token consumption.

Access the dashboard locally at:
`http://127.0.0.1:9317/dashboard`

---

## Core Sections

### 1. Traces & Request Logs

Inspect incoming and outgoing requests in real time. Click any trace to review TTFT, full latency breakdown, token usage, and failover history.

### 2. Providers Management

Create, edit, test, and delete API and OAuth providers. Trigger live probes on any provider card to verify upstream health.

### 3. Usage & Cost Analytics

Track aggregated token consumption, model request volume, and estimated dollar costs across custom time windows.

### 4. System Settings & Configuration

Preview the active runtime configuration, inspect environment variables, and manage authentication credentials.
