# Usage & Cost Analytics

AIO Proxy automatically computes estimated API expenses by pairing token counts with model pricing defined in `catalog`.

## Key Capabilities

- **Model Breakdown**: See which models consume the most tokens.
- **Provider Breakdown**: Compare actual spend across different upstreams.
- **Cached Token Savings**: Measure the cost benefits of prompt caching across Anthropic and OpenAI.
