# Create a message

`POST /v1/messages`

Creates an Anthropic-compatible message. Set `stream: true` to receive a streaming response. Requests are parsed against this endpoint's schema. A same-protocol provider with raw capability receives the raw-forwarded request after routing rewrites; cross-protocol and AI SDK providers receive a converted model request, so fields that cannot be represented by the target protocol are not forwarded. Try It runs in your browser, so the selected server must allow cross-origin requests, and an HTTPS documentation page cannot call an HTTP server because browsers block mixed content. Try It sends the request, but Scalar does not provide a separate streaming debugger; use the SSE example when the panel does not render events.

**Parameters:** `conversation_id`, `max_tokens`, `messages`, `metadata`, `model`, `output_config`, `service_tier`, `session_id`, `speed`, `stream`, `system`, `temperature`, `thinking`, `tools`

**Responses:** `200 application/json`, `200 text/event-stream`
