# List models

`GET /v1/models`

Lists the models currently available through aio-proxy. Try It runs in your browser, so the selected server must allow cross-origin requests, and an HTTPS documentation page cannot call an HTTP server because browsers block mixed content.

**Parameters:** None

**Responses:** `200 application/json`
