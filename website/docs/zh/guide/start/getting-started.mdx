# 快速开始

本篇指南将带你在几分钟内启动 AIO Proxy，接入首个模型提供商，并通过统一端点发出第一条请求。

> 如果你尚未安装 AIO Proxy，请先参阅 [安装指南](./install-deploy/installation)。

## 1. 启动服务

在终端运行以下命令启动 AIO Proxy：

```sh
aio-proxy run --open
```

首次启动会自动在用户目录创建默认配置文件 `~/.aio-proxy/config.jsonc`，并在系统默认浏览器中打开 Dashboard 控制台：

- **API 服务端点**：`http://127.0.0.1:9317`
- **Dashboard 控制台**：`http://127.0.0.1:9317/dashboard`

初始配置不包含任何提供商。接下来任选一种方式添加你的第一个提供商。

## 2. 添加模型提供商

### 方式一：在 Dashboard 中添加（推荐）

1. 在打开的 Dashboard 页面中，点击左侧导航栏的 **“提供商 (Providers)”**。
2. 点击右上角 **“添加提供商”**，选择 API 提供商。
3. 填写提供商名称、上游 Base URL（如 OpenAI 或任意兼容平台）、API 密钥以及公开的模型名称（例如 `gpt-5`）。
4. 保存后点击提供商卡片上的 **“测试”** 探针按钮，确认上游连接正常。

### 方式二：直接编辑配置文件

先在终端设置你的上游 API 密钥：

```sh
export OPENAI_API_KEY='your-api-key'
```

使用内置命令打开配置文件：

```sh
aio-proxy config edit
```

在 `providers` 对象中加入提供商配置：

```jsonc title="config.jsonc"
{
  "$schema": "https://unpkg.com/@aio-proxy/types/config.schema.json",
  "providers": {
    "openai": {
      "kind": "api",
      "protocol": "openai-response",
      "baseURL": "https://api.openai.com/v1",
      "apiKey": "{{env.OPENAI_API_KEY}}",
      "models": ["gpt-5"],
    },
  },
}
```

校验并热重载配置：

```sh
aio-proxy config validate
aio-proxy reload
```

`openai` 是该提供商的稳定提供商 ID；`gpt-5` 是它向客户端公开的模型名。后续你可以为同一个模型名称添加更多提供商以实现多渠道自动故障切换。

## 3. 发出第一条请求

打开新终端窗口，使用 curl 发送一条测试请求：

```sh
curl http://127.0.0.1:9317/v1/responses \
  -H 'Content-Type: application/json' \
  -d '{"model":"gpt-5","input":"用一句话介绍 AIO Proxy。"}'
```

请求成功后，响应会由已配置的上游提供商返回。

回到 Dashboard 的 **“请求追踪 (Traces)”** 页面，你可以实时查看这次调用的完整链路详情、首字生成延迟 (TTFT)、Token 消耗量与往返耗时。
