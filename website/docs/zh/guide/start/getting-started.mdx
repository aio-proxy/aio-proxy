# 快速开始

这篇指南会在本机启动 AIO Proxy，添加一个 OpenAI Responses 提供商，并通过本地端点发出第一条请求。

## 安装

<CommandTabs
  commands={{
    brew: 'brew install aio-proxy/tap/aio-proxy',
    bun: 'bun add -g aio-proxy',
  }}
/>

## 启动服务

```sh
aio-proxy run --open
```

npm/bun 还会安装短命令 `aiop`。Homebrew 目前仍只有 `aio-proxy`。

首次启动会创建 `~/.aio-proxy/config.jsonc`，并打开 Dashboard。默认地址为：

- API：`http://127.0.0.1:9317`
- Dashboard：`http://127.0.0.1:9317/dashboard`

初始配置不包含提供商。接下来任选一种方式添加第一个提供商。

## 方式一：在 Dashboard 中添加

在 Dashboard 的提供商页面添加一个 API 提供商。填写上游地址、认证信息和模型；模型名需要与客户端请求中的模型名一致。

保存后，使用页面中的测试功能确认提供商可用。你可以随时回到 Dashboard 编辑、测试或删除提供商。

## 方式二：编辑配置文件

先在终端设置 API 密钥：

```sh
export OPENAI_API_KEY='your-api-key'
```

打开配置文件：

```sh
aio-proxy config edit
```

加入下面的提供商配置：

```jsonc title="config.jsonc"
{
  "$schema": "https://cdn.jsdelivr.net/npm/aio-proxy@latest/config.schema.json",
  "providers": {
    "openai": {
      "kind": "api",
      "protocol": "openai-response",
      "baseURL": "https://api.openai.com/v1",
      "apiKey": "{{env.OPENAI_API_KEY}}",
      "models": ["gpt-5"],
    },
  },
}
```

验证并重新加载配置：

```sh
aio-proxy config validate
aio-proxy reload
```

`openai` 是这个提供商的提供商 ID；`gpt-5` 是它向客户端公开的模型名。后续可为同一个模型添加更多提供商。

> 原生支持多种协议的上游（Moonshot、z.ai、聚合网关等）可以额外声明 `endpoints`，命中的请求会被原样转发而不经过协议转换。完整规则见 README 的“多协议端点”一节。

## 发出第一条请求

```sh
curl http://127.0.0.1:9317/v1/responses \
  -H 'Content-Type: application/json' \
  -d '{"model":"gpt-5","input":"用一句话介绍 AIO Proxy。"}'
```

请求成功后，响应会由已配置的提供商返回。也可以在 Dashboard 的请求记录中查看这次调用。
