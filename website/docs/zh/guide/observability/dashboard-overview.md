# 控制台概览

AIO Proxy 自带开箱即用的现代化可视化管理后台（Dashboard），默认运行在：

```text
http://127.0.0.1:9317/dashboard
```

在服务启动时附带 `--open` 参数，或随时执行以下命令，会自动在系统默认浏览器中打开控制台：

```sh
aio-proxy dashboard
```

## 核心管理模块

1. **概览面板 (Overview)**：展示今日与近期的请求总量、Token 吞吐量、折算费用、活跃模型分布与近期调用趋势。
2. **提供商管理 (Providers)**：
   - 查看所有已配置的 API 提供商与 OAuth 账号。
   - 实时在线探针测试：点击“测试”对指定 Provider 发起轻量健康探测（验证 Base URL 连通性、API Key 有效性与模型响应）。
   - 一键 OAuth 授权与重授权（ChatGPT、Claude、Cursor、Copilot 等）。
   - 动态调整 Priority 故障层级与 Weight 流量权重。
3. **请求追踪 (Traces)**：查看每一条流经代理的完整请求，包含首字延迟 (TTFT)、总耗时、候选回退过程与完整 Payload。
4. **用量分析 (Usage)**：按模型、按提供商多维拆解 Token 输入、输出与 Cache 命中，提供详细的日历热力图与成本报表。
5. **系统设置 (Settings)**：查看当前运行端口、全局网络代理状态、主备代理策略以及版本信息。

## 安全与密码机制

- **密码配置**：在 `server.password` 中设置密码明文或 Argon2id PHC 哈希。
- **免反复登录**：首次输入密码通过验证后，登录凭据会在浏览器本地建立长效安全会话。只要每 6 天内访问一次，会话就会自动滑动续期，无需反复认证。
- **即时失效**：在配置文件中修改 `password` 后，所有设备上的已登录会话会立即全局作废。
