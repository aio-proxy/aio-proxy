# 计算内容 Token `POST /v1beta/models/{model}:countTokens`

使用 URL 中的模型计算 Gemini contents 的 Token，返回 totalTokens，而非生成内容。

<details>
<summary>参数 / 响应</summary>

**参数:** `contents`, `conversation_id`, `generationConfig`, `model`, `safetySettings`, `session_id`, `systemInstruction`, `tools`

**响应:** `200 application/json`

</details>
