# 创建聊天补全

`POST /v1/chat/completions`

创建 OpenAI 兼容的聊天补全。

**参数:** `conversation_id`, `max_completion_tokens`, `max_tokens`, `messages`, `metadata`, `model`, `prompt_cache_key`, `reasoning_effort`, `response_format`, `service_tier`, `session_id`, `stream`, `temperature`, `tool_choice`, `tools`

**响应:** `200 application/json`, `200 text/event-stream`
