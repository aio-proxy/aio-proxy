# 创建消息

`POST /v1/messages`

创建 Anthropic 兼容消息。

**参数:** `conversation_id`, `max_tokens`, `messages`, `metadata`, `model`, `output_config`, `service_tier`, `session_id`, `speed`, `stream`, `system`, `temperature`, `thinking`, `tools`

**响应:** `200 application/json`, `200 text/event-stream`
