# 生成语音 `POST /v1/audio/speech`

返回音频二进制而非 JSON。

<details>
<summary>参数 / 响应</summary>

**参数:** `input`, `instructions`, `model`, `response_format`, `speed`, `stream_format`, `voice`

**响应:** `200 application/octet-stream`, `200 audio/mpeg`, `200 audio/wav`, `200 text/event-stream`
