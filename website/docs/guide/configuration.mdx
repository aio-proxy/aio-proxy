# Configuration

The first run creates ~/.aio-proxy/config.jsonc. Each key in providers is a stable **Provider ID**.

```jsonc
{
  "$schema": "https://cdn.jsdelivr.net/npm/aio-proxy@latest/config.schema.json",
  "providers": {
    "openai": {
      "kind": "api",
      "protocol": "openai-response",
      "baseURL": "https://api.openai.com/v1",
      "apiKey": "{{env.OPENAI_API_KEY}}",
      "models": ["gpt-5"],
    },
  },
}
```

Validate and reload:

```sh
aio-proxy config validate
aio-proxy reload
```
