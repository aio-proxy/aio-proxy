# Website Isolation Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Move the documentation site to top-level `website/` and prevent root
development, build, and preflight commands from including it.

**Architecture:** `website` remains an explicitly declared Bun workspace so
its existing `workspace:*` UI dependency and `catalog:` versions keep working.
Root scripts filter the package out; the site retains its own Rspress scripts
for explicit use.

**Tech Stack:** Bun workspaces and lockfile, Turborepo task filters, Rspress,
Oxlint, Oxfmt.

## Global Constraints

- Keep `@aio-proxy/website` dependent on the local `@aio-proxy/ui` package.
- Do not change documentation content, Rspress configuration, release config,
  or Changesets.
- Root `dev`, `build`, test, e2e, and `preflight` commands must skip
  `@aio-proxy/website`.
- Regenerate the root Bun lockfile after the workspace path move.

---

### Task 1: Move and isolate the documentation workspace

**Files:**
- Move: `packages/website/` to `website/`
- Modify: `package.json`
- Modify: `bun.lock` (generated by Bun)
- Test: Turbo dry-run and package-script assertions; no source-level test is
  appropriate because this task only changes workspace and command routing.

**Interfaces:**
- Consumes: package name `@aio-proxy/website`, root workspace catalog, and
  Turborepo's `--filter=!<package>` selector.
- Produces: a top-level workspace that runs only through explicit website
  commands, such as `bun run --filter @aio-proxy/website dev`.

- [ ] **Step 1: Establish the failing routing check**

Run the following commands before changing configuration. Each must find the
website package, proving the requested isolation has not yet been implemented.

```bash
bunx --no-install turbo run build --dry=json | rg '"package": "@aio-proxy/website"'
bunx --no-install turbo run dev serve:dev --dry=json | rg '"package": "@aio-proxy/website"'
bunx --no-install turbo run test test:artifact --dry=json | rg '"package": "@aio-proxy/website"'
bunx --no-install turbo run e2e --dry=json | rg '"package": "@aio-proxy/website"'
```

Expected: every command prints a matching task. Treat this as the red state
for the desired "not included" behavior.

- [ ] **Step 2: Move the site and update root routing**

Run:

```bash
git mv packages/website website
```

Then update `package.json` as follows:

```json
{
  "workspaces": {
    "packages": ["packages/*", "packages/plugins/*", "npm/*", "website"]
  },
  "scripts": {
    "lint": "oxlint --ignore-pattern='website/**' .",
    "lint:types": "oxlint --type-aware --type-check --ignore-pattern='website/**' --ignore-pattern='**/*.test.ts' --ignore-pattern='**/*.test.tsx' --ignore-pattern='**/__tests__/**' --ignore-pattern='**/*test-support.ts' --ignore-pattern='**/test-support/**' --ignore-pattern='**/*.smoke.ts' .",
    "format": "oxfmt . '!website/**'",
    "format:check": "oxfmt --check . '!website/**'",
    "test:unit": "turbo run test:unit --filter=!@aio-proxy/website",
    "test:artifact": "turbo run test:artifact --filter=!@aio-proxy/website",
    "test": "turbo run test test:artifact --filter=!@aio-proxy/website",
    "e2e": "turbo run e2e --filter=!@aio-proxy/website",
    "build": "turbo run build --filter=!@aio-proxy/website",
    "dev": "bun run dev:prepare && AIO_PROXY_PORT=22078 turbo run dev serve:dev --filter=!@aio-proxy/infra --filter=!@aio-proxy/website"
  }
}
```

Keep every unrelated `package.json` entry unchanged. The website package name,
its `workspace:*` dependency, and its `catalog:` versions remain unchanged.

- [ ] **Step 3: Regenerate the workspace lockfile**

Run:

```bash
bun install
```

Expected: `bun.lock` replaces workspace path `packages/website` with
`website`; it must not create a nested website lockfile.

- [ ] **Step 4: Verify the green routing and standalone build**

Run:

```bash
if bunx --no-install turbo run build --filter=!@aio-proxy/website --dry=json | rg -q '"package": "@aio-proxy/website"'; then
  echo 'root build still includes website' >&2
  exit 1
fi
if bunx --no-install turbo run dev serve:dev --filter=!@aio-proxy/infra --filter=!@aio-proxy/website --dry=json | rg -q '"package": "@aio-proxy/website"'; then
  echo 'root dev still includes website' >&2
  exit 1
fi
if bunx --no-install turbo run test test:artifact --filter=!@aio-proxy/website --dry=json | rg -q '"package": "@aio-proxy/website"'; then
  echo 'root test still includes website' >&2
  exit 1
fi
if bunx --no-install turbo run e2e --filter=!@aio-proxy/website --dry=json | rg -q '"package": "@aio-proxy/website"'; then
  echo 'root e2e still includes website' >&2
  exit 1
fi
bun run --filter @aio-proxy/website build
bun run preflight
```

Expected: every routing assertion exits zero without output, the Rspress build
passes, and root preflight passes while its lint, format, and test commands
exclude `website/**` and `@aio-proxy/website`.
