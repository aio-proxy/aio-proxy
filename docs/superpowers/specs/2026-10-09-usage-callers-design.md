# 使用者消耗统计

共享代理时，每位使用者分配一个带标签的 API 密钥。开启密钥访问时，首页默认按费用展示使用者排名，支持切换 Token 和请求数，并显示其在当前时间范围内的占比；只有一位使用者时仍显示，关闭密钥访问则隐藏整个排名模块。排名是 KPI 与模型趋势之间的独立看板，不替换原有模型内容。点击使用者或在页首选择使用者后，KPI、同期对比、模型趋势、Provider 健康度、模型排行和热力图均使用该身份的数据，排名隐藏；选择全部且已开启密钥访问时恢复排名。热力图仍使用原有滚动 52 周时间范围。

## 身份和标签

- 保存密钥时标签必填，去除首尾空白，最多 40 个字符；标签、密钥和显式身份 ID 必须分别唯一。
- 已有无标签配置兼容启动，统计显示自动生成的 `Key <身份短码>`；编辑保存时必须补齐标签。
- 新增、编辑保存的配置会持久化随机 UUID `id`。重命名和轮换密钥时保留该 ID；直接编辑配置或轮换环境变量时也应保留它。
- 无显式 ID 的旧配置由数据库内的凭证映射获得随机身份。映射使用数据库独有的持久 HMAC 密钥，接口只暴露随机身份和标签，不暴露凭证或摘要。
- 已删除密钥的历史身份仍可筛选。排名使用最新标签，追踪保留请求发生时的标签快照。
- 未匹配密钥且允许访问的请求属于匿名访问。升级前的使用量单列为历史未归属，不推测归属。Agent 凭证按安装 ID 单列，刷新令牌不改变归属。

## 持久化与查询

鉴权确认身份后，通过请求作用域传给根追踪记录。根 span 保存使用者 ID、标签和类别；这些字段在禁止请求正文采集时仍保留。未通过鉴权的请求不产生使用量。原有 realtime/video 所有权身份逻辑保持独立。

`usage_daily` 继续提供全局日聚合，`usage_caller_daily` 按使用者、日期、模型持久化相同计数和费用字段。完成请求时同一事务更新两个聚合，重复结算不增加计数。中断恢复也保留使用者。迁移将已有日聚合复制到历史未归属；新记录仅累计一次。24 小时查询读取根追踪，长时间范围及热力图读取日聚合，因而超过 45 天追踪保留期限仍有使用量。

所有金额以纳美元十进制字符串传输，累计使用 bigint。未定价请求仍计入请求数、Token，费用只包含已定价用量。

Dashboard API 扩展：

- `/overview`、`/overview/diagnostics`、`/overview/activity` 接收可选 `callerId`。
- `/overview/callers` 提供可筛选身份，不返回密钥。
- `/overview/caller-ranking?range=...` 提供当前窗口各使用者的请求数、Token 和费用。
- `/traces`、`/traces/summary` 接收 `callerId`；列表及详情提供使用者快照。筛选变更重置分页，图和表使用同一筛选条件。

## 验收

自动化覆盖各看板筛选一致性、同期对比、重试后单次计数、重复结算、中断恢复、追踪清理后长期统计、大整数精度、重启/改标签/轮换身份连续性、标签校验及拒绝写入、真实鉴权请求归属和凭证不进入统计/追踪/上游。

隔离实例使用真实 Dashboard API 与本地测试上游，验证全部/单人切换、独立指标选择、追踪列表筛选、必填及重复标签拦截；390px 宽度无页面横向溢出。用户现有代理配置及流量未用于验收。
